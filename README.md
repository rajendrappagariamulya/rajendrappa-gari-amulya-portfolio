# RAJENDRAPPA GARI AMULYA — Portfolio

A modern, responsive developer portfolio showcasing Java full-stack applications, skills, and projects.

**Live site:** https://YOUR-SITE-URL/

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- AOS (Animate on Scroll)
- EmailJS
- WebGL (Fluid splash cursor)

## Run Locally

```bash
# Clone the repository
git clone https://github.com/rajendrappagariamulya/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Environment Variables

To configure the contact form via EmailJS, copy `.env.example` to `.env.local` and define:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
